# Курсовая работа №2: Сервис генерации экзаменационных билетов (Examiner Service)

Проект представляет собой бэкенд-приложение на базе **Spring Boot**, предназначенное для создания случайных экзаменационных билетов по Java.

## 🛠️ Выполненные задачи и архитектура
* **Domain слой:** Создана модель данных `Question` с инкапсулированными private-полями, геттерами, переопределёнными методами `equals()`, `hashCode()` и `toString()`.
* **Service слой:**
    * Реализован интерфейс `QuestionService` и сервис `JavaQuestionService`, управляющий уникальным хранилищем вопросов на базе коллекции `Set<Question>`.
    * Реализован интерфейс `ExaminerService` и сервис `ExaminerServiceImpl`, отвечающий за сборку случайных экзаменационных билетов заданной длины без дубликатов.
* **Controller слой:**
    * Добавлен `JavaController` для администрирования вопросов через HTTP-методы (`POST /exam/java/add`, `DELETE /exam/java/remove`, `GET /exam/java`).
    * Добавлен `ExamController` для выдачи случайных билетов пользователю по эндпоинту `GET /exam/get/{amount}`.
* **Exception слой:** Реализовано кастомное исключение `BadAmountException` с аннотацией `@ResponseStatus(HttpStatus.BAD_REQUEST)`, срабатывающее при запросе большего количества вопросов, чем доступно в базе.

## 🧪 Тестирование (Unit-тесты)
* Бизнес-логика приложения полностью покрыта юнит-тестами с использованием фреймворков **JUnit 5** и **Mockito**.
* Реализованы `JavaQuestionServiceTest` и `ExaminerServiceImplTest`, проверяющие граничные условия:
    * Поведение системы при пустом хранилище вопросов.
    * Фильтрацию дубликатов при добавлении.
    * Валидацию некорректного ввода количества вопросов (`amount = 0`, `amount > size`).
